# 차곡차곡 쌓기 연구소

초등학교 특수교육대상학생이 쌓기나무를 위, 앞, 왼쪽, 오른쪽에서 본 모양으로 표현하는 연습을 할 수 있는 웹앱입니다.

## 실행하기

별도의 설치 과정이 없습니다. `index.html`을 Chrome, Edge 등의 웹 브라우저에서 열면 바로 사용할 수 있습니다.

## 조작 방법

화면을 전환하지 않고 입체 공간과 네 방향의 5×5 모눈종이를 함께 조작할 수 있습니다.

1. 입체 공간을 짧게 누르면 블록이 쌓입니다.
2. 입체 공간을 드래그하면 모양을 자유롭게 돌려 볼 수 있습니다.
3. 블록을 꾹 누르면 깨지는 효과와 함께 블록이 하나 사라집니다.
4. 오른쪽의 위·앞·왼쪽·오른쪽 5×5 모눈종이에 보이는 모양을 그립니다.
5. `네 방향 확인하기` 버튼으로 한꺼번에 확인합니다.

학생이 처음 사용할 때는 `계단 모양`, `기역 모양`, `작은 산` 예시부터 시작하는 것을 권장합니다.
